@startuml
title Secure User Authentication Flow

actor User
participant "Web Application" as App
participant "Authentication Service" as Auth
database "Database" as DB
participant "Security Controls" as Security

User -> App: Enter username & password
App -> Security: Validate input
Security --> App: Input is safe

App -> Auth: Authenticate user
Auth -> DB: Verify password hash
DB --> Auth: User verified
Auth --> App: Authentication successful

App -> Security: Create secure session
Security --> App: Session ID + CSRF token

App --> User: Dashboard

note right of Security
Security measures:
- HTTPS/TLS
- Password hashing
- MFA
- CSRF protection
- Input validation
- Rate limiting
- Audit logging
end note

@enduml
