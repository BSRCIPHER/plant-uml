@startuml

title GitHub OAuth Integration

actor User
participant "Forge App" as Forge
participant "GitHub" as GitHub
database "Forge KVS" as KVS

User -> Forge: Click Connect GitHub
Forge -> GitHub: Authorization request
GitHub -> User: Login / Authorize
User -> GitHub: Approve access
GitHub -> Forge: Authorization code

Forge -> GitHub: Exchange code for token
GitHub --> Forge: Access token

Forge -> KVS: setSecret(userId, token)
KVS --> Forge: Success

Forge --> User: GitHub connected

User -> Forge: Get repositories
Forge -> KVS: getSecret(userId)
KVS --> Forge: Access token

Forge -> GitHub: GET repositories
GitHub --> Forge: Repository data
Forge --> User: Display repositories

@enduml
